## 3. 상세 분석

### RTX 5090 Desktop — 최적 추천 ★

- FP32 105 TFLOPS → 5080 Laptop의 **4.6배** (실측 ~5배 예상)
- VRAM 32GB → 24,576 envs에 여유
- 대역폭 1,792 GB/s → 3.1배 향상
- 15,000 iter 예상 소요: **~20시간** (현재 104시간)
- **가격 대비 속도 향상 최고**

### RTX 5090 Laptop — 비추

- FP32 33.7 TFLOPS → 1.5배밖에 안 됨 (노트북 전력 제한)
- 가격 $3,000 → 5090 Desktop보다 비싸면서 3배 느림

### DGX Spark — 이 작업에 부적합

- GPU는 Grace 기반 통합칩 (FP32 2.0 TFLOPS)
- 128GB 통합 메모리가 장점이나 RL은 VRAM보다 **FP32 연산이 병목**
- Isaac Lab 물리 시뮬레이션은 단일 GPU 전용 → 멀티 노드 불가
- DGX Spark x2로도 Isaac Lab 확장 불가

### A4000 — 의미 없음

- FP32 19.2 TFLOPS → 현재 5080과 거의 동일
- VRAM 16GB, 대역폭 448 GB/s → 오히려 열세
- 업그레이드 효과 제로

### L40S — 오버스펙

- 성능은 5090 Desktop과 비슷하나 가격 3.5~5배
- 48GB VRAM은 이 프로젝트에선 불필요 (16GB로 24,576 envs 가능)
- 데이터센터 전용 → 별도 서버 필요
