**목표**: residency reward 활성화 + front dominance 억제

## V29.2 변경사항

### 1. contact_residency band 확장

```
band_low : 0.25 → 0.20  (RL/RR 에피소드 초반 band 진입 가능)
band_high: 0.65 → 0.85  (FL/FR 0.84도 band 안 → residency reward 활성화)
```

**기대**: FL/FR도 residency reward를 받게 되어 [0.20, 0.85] 범위 유지 인센티브 형성.

### 2. prop_residency band_high 완화

```
band_high: 0.65 → 0.70  (FL/FR propulsion 0.64~0.66 포함)
```

### 3. per_leg_contact_target_band 강화

```
band_high: 0.45 → 0.75  (RL/RR 0.48~0.53이 band 안에 포함)
weight   : 0.5  → 3.0   (실질 gradient 생성)
```

**기대**: RL/RR이 [0.20, 0.75] band 안에서 즉각 양의 reward 수신. FL/FR(0.84)은 여전히 band 밖 → RL/RR 상대 우위.

### 4. front_rear_support_balance_penalty 활성화

```
weight  : 0.0  → -4.0
max_diff: 0.50 → 0.25
```

- 현재 gap = 0.36 > 0.25 → iter 0부터 즉각 패널티
- front dominance 구조에 명시적 penalty gradient

**기대**: FL/FR contact이 높을수록 패널티 강화 → 뒷다리로 하중 분산 유도.

### 5. residency enforce 타이밍 지연

```
residency_relay_up_start : 600 → 800
residency_relay_up_end   : 800 → 1000
residency_relay_down_end : 1000 → 1200
```

- gait B 수준(iter ~500) 달성 후 200 iter 추가 안정화 기간 확보
- enforce 진입 시 이미 걸음새 안정화된 상태

### 6. KPI 경보 임계값 현실화

```
RR residency 경보: 0.30 → 0.15
```

V29 실측 최대 달성값: ~0.134. 0.30은 비현실적 목표였음.
