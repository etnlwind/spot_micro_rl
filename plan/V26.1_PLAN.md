## V26.1 한 줄 정의

**4발 존재 보장 + 하중 분산을 일반(대칭) 구조만으로 해결할 수 있는지 검증한다.**

V25 실패 교훈: 특정 다리 지목 penalty → collapse 위치 이동. V26.1은 모든 다리에 동일 기준을 적용한다.

## 구현할 reward term (8개 고정)

| # | 이름 | 역할 | 구분 |
|---|------|------|------|
| 1 | `limb_usage_min_penalty` | 4개 중 하나라도 usage 낮으면 강하게 감점 | Existence Floor |
| 2 | `per_leg_contact_floor_penalty` | 각 다리 최소 contact 보장 | Existence Floor |
| 3 | `per_leg_propulsion_floor_penalty` | 각 다리 최소 propulsion 보장 (fake contact 차단) | Existence Floor |
| 4 | `rear_left_right_usage_diff_penalty` | 뒷다리 좌우 usage 편중 억제 | Load Sharing |
| 5 | `front_left_right_usage_diff_penalty` | 앞다리 좌우 usage 편중 억제 | Load Sharing |
| 6 | `rear_left_right_propulsion_diff_penalty` | 뒷다리 좌우 추진 편중 억제 | Load Sharing |
| 7 | `front_rear_support_balance_penalty` | 앞/뒤 전체 지지 편중 억제 | Load Sharing |
| 8 | `diagonal_coupling_soft_gate` | collapse 다리 포함 diagonal reward soft attenuation | Exploit 차단 |

**제외 (V26.2로 이월)**: contact_oscillation, touchdown_impact, micro_step, stance_quality

## Floor threshold 확정값

V25 iter 400 실측 기준:
- 붕괴 다리 (rr): usage=0.003, contact=0.011, propulsion=0.009
- 정상 다리 (rl): usage=0.930, contact=0.693, propulsion=0.516

| 항목 | threshold | penalty 구조 |
|------|----------|-------------|
| per-leg contact floor | **0.10** | soft (연속), 이하일수록 강화 |
| per-leg propulsion floor | **0.05** | soft, fake contact 차단 |
| per-leg usage floor | **0.10** | soft |
| left/right usage diff | **> 0.40** | soft |
| left/right propulsion diff | **> 0.40** | soft |
| front/rear support diff | **> 0.50** | soft (앞뒤는 구조상 비대칭 허용) |

모든 penalty는 soft (연속 함수). binary 금지.

## 판정 기준

### iter 200 — 경고 기준
아래 중 하나라도:
- 어떤 다리든 `contact_ratio < 0.05`
- 어떤 다리든 `swing_time > 0.95`
- 어떤 다리든 `propulsion ≈ 0`

→ CRITICAL 알림. 계속 관찰.

### iter 300 — 중단 검토
위 패턴 지속 시 → V26.1 실패 판정. V26.2 (direct-fix 추가) 전환 검토.

### iter 400 — 기본 중단값
아래 중 하나라도 지속:
- 어떤 다리든 `contact_ratio < 0.02`
- 어떤 다리든 `propulsion < 0.02`
- `Limb Validity Gate = FAIL`

→ 즉시 중단. reward/survival 무관.

### iter 600 — 무조건 중단
single-limb collapse 지속 시 reward 높아도 중단.

## 성공/실패 기준

### 성공
- 4다리 모두 contact / propulsion 실제 참여
- 어느 다리도 collapse 없음
- 하중 편중 완화
- 결과적으로 자연스러운 보행

### 실패
- reward/survival 높아도 특정 다리 usage collapse → **실패**
- contact 살아도 propulsion 0 → **실패 (fake contact)**
- collapse 위치만 바뀜 (V25 패턴 반복) → **실패**
