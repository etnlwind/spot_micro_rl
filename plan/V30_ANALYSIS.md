## 핵심 발견

### 1. 초기 자세 대칭 → 학습 효율 대폭 향상

V30의 대칭 init pose(leg=-0.71, foot=1.31, height=0.192)는:
- reward 322 (V29 max 303) — 동일 iter에서 더 높은 reward
- 생존율 거의 100% — episode length 248/250
- bad_orientation 2.2% (V29: 54%→2%) — 훨씬 빠른 안정화
- velocity_tracking 0.77 (V29: 0.5) — 더 나은 속도 추종

### 2. Front contact lock-in은 물리 자세가 아닌 reward 구조 문제

```
V30 FL/FR contact 추이:
iter 200: 0.710 (혼돈기 — 낮음)
iter 300: 0.795 (급등)
iter 500: 0.818 (수렴)
iter 724: 0.834 (V29의 0.845를 향해 접근 중)
```

대칭 자세에서도 FL/FR lock-in 방향이 동일 → **물리적 비대칭은 촉진 요인이었지 근본 원인이 아님**.
근본 원인: reward 구조에 앞다리 swing 인센티브가 전무 (뒷다리에만 5개 전용 보상 존재).

### 3. Reward 급락 = V29와 동일 패턴

iter 644→724에서 reward 323→257 급락.
원인: `late_phase_band_exit` 패널티가 -3.78 → -11.60으로 3배 증가 (iter 600~900 ramp).
FL/FR이 band 밖(>0.85)에서 패널티만 누적, 행동 변화 없음 → V29와 동일한 실패 경로.
