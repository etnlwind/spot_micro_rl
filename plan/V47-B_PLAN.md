### 한계: 부자연스러운 자세

영상 리뷰에서 발견된 3가지 문제:

**문제 1: 몸이 너무 낮음 (엎드려 기어가는 느낌)**
```
target_height = 0.23m
실제: 그보다 낮게 주저앉아 있음
원인: 몸을 낮추면 안정적 → ep_len↑ → alive_bonus(+7.89)↑
      base_height_l2(-0.20)가 너무 약해서 높이 유지를 강제 못함
```

**문제 2: 뒷다리 과도한 꺽임 (무릎이 몸보다 높음)**
```
leg_lift: target_angle 0.6 rad (34도) — 자연 보행(15~25도)의 1.5~2배
rear_joint_velocity(+9.43) + leg_lift(+0.68) = +10.11 vs dof_limits(-3.76)
→ 과도하게 움직이는 게 +6.35 이득 → reward hacking
```

**문제 3: 앞뒤 다리 간 거리 불자연 (wheelbase 짧음)**
```
몸이 낮음 → 다리가 접힘 → 앞뒤 발끝 거리가 짧아짐
자연스러운 서기: 다리가 몸 아래로 곧게 뻗음 (사진 참조)
현재: 다리가 꺽여서 옆으로 펼쳐짐
```

### 근본 원인: Reward Hacking

```
자연스러운 자세 (높이 유지, 다리 펴기):
  base_height(+0.13) + standing_height(+0.13) = +0.26 인센티브

부자연스러운 자세 (낮게, 다리 꺽기):
  안정성 → alive_bonus(+7.89) + rear_joint_vel(+9.43) + leg_lift(+6.66) = +24 인센티브

→ 부자연스러운 자세가 24배 이득 → PPO는 당연히 부자연스러운 쪽 선택
```

## 3. V47-B 변경 사항

### 변경 1: 몸 높이 유지 강화

```
base_height_l2:  weight -15 → -30 (2배 강화)
standing_height: weight +10 → +20 (2배 강화)
→ 몸을 낮추면 큰 벌칙, 높이 유지하면 큰 보상
→ 높이 인센티브: 0.26 → ~1.0 (4배 증가)
```

### 변경 2: 다리 들기 각도 제한

```
leg_lift target_angle: 0.6 rad (34도) → 0.4 rad (23도)
→ 자연 보행 범위(15~25도) 내로 제한
→ 23도 이상 들어올려도 보상 cap (1.0)
→ 과도한 꺽임 인센티브 감소
→ 4발 공통 적용 (FL/FR/RL/RR). 실제 영향은 rear 중심 (현재 RL=0.68, RR=0.49 vs FL=0.01)
```

### 변경 3: 관절 한계 벌칙 강화

```
dof_pos_limits: weight -5 → -15 (3배 강화)
→ 현재: rear_joint(+10.11) vs limits(-3.76) = 과도 움직임 이득(+6.35)
→ 변경: rear_joint(+10.11) vs limits(-11.28) = 과도 움직임 손해(-1.17)
→ 부자연스러운 극단 자세가 손해로 전환
```

### 변경하지 않는 것

```
- V38.3 reward 구조 전체 (77개 유지)
- boot_standing / boot_contact (유지)
- CaT / shoulder_neutral (유지)
- curriculum 구조 (유지)
- stride/coupling 관련 reward weight (유지)
```

## 4. 변경의 상호작용 분석

### 높이 강화 + stride 영향

```
몸이 높아지면:
  + 다리가 자연스럽게 펴짐 → 보폭 효율 증가
  + 무릎이 몸 아래로 내려옴
  - 무게중심이 높아져 약간 불안정 → ep_len 약간 하락 가능

예상: stride 5.5~6.0 (약간 하락 가능, but 자세 개선)
```

### 다리 각도 제한 + stride 영향

```
leg_lift target 0.6→0.4:
  + 과도한 꺽임 방지
  + 자연스러운 스윙
  - 극단적으로 높이 들어올리는 보폭 감소

예상: stride 5.0~6.0 (leg_lift 기여분 감소, but 효율적 보폭으로 보완)
```

### 관절 한계 강화 + stride 영향

```
dof_pos_limits -5→-15:
  + 관절 극단 자세 억제
  + 자연스러운 관절 범위 유지
  - 관절 움직임 범위 약간 축소

예상: stride 5.5~6.0 (극단 자세에 의존하던 보폭 감소)
```

### 종합 예상

```
V47:    stride 6.21, 부자연스러운 자세
V47-B:  stride 5.0~6.0, 자연스러운 자세
→ stride 약간 하락 가능하지만, 자세 품질 대폭 개선
```

## 6. 리스크

### 1. 높이 강화로 ep_len 급락
- 높이 유지 → 불안정 → 넘어짐 증가
- 감지: iter 500 ep_len < 150
- 대비: base_height_l2 -30 → -20 완화

### 2. 관절 제한으로 stride 급락
- 과도한 제한 → 움직임 축소 → stride < 3.0
- 감지: iter 2000 stride < 3.0
- 대비: dof_pos_limits -15 → -10 완화

### 3. 3개 변경 동시 적용 — 원인 분리 어려움
- 높이/각도/한계를 동시에 바꾸면 뭐가 효과인지 모름
- 완화: 3개 모두 "자세 품질" 단일 축이라 동시 적용 타당
  - 높이↑ + 각도↓ + 한계↑ = 모두 "자연스러운 서기" 방향
  - V44에서 "독립적 축은 동시 변경 가능" 원칙과 일치
