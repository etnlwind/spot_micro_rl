## 3. 구체적 수정 사항

### 3.1 수정 B: `excessive_joint_oscillation_penalty` 신설 (★★★ 최고 우선)

**목적**: 개별 관절이 비정상적으로 빠르게 진동하는 것을 직접 억제

```python
def excessive_joint_oscillation_penalty(
    env: ManagerBasedRLEnv,
    asset_cfg: SceneEntityCfg = SceneEntityCfg("robot"),
    max_vel_per_joint: float = 5.0,
) -> torch.Tensor:
    """개별 관절 속도가 max_vel_per_joint를 초과하면 페널티.
    고속 떨기(20+ rad/s)를 직접 억제."""
    asset: Articulation = env.scene[asset_cfg.name]
    joint_vel = torch.abs(asset.data.joint_vel[:, asset_cfg.joint_ids])
    excess = torch.clamp(joint_vel - max_vel_per_joint, min=0.0)
    return excess.mean(dim=1)
```

**파라미터**:
- `max_vel_per_joint = 5.0 rad/s` (정상 보행 시 ~3~5, 벌레떨기 시 ~20)
- 12개 전체 관절 대상

**Phase별 가중치**:

| Phase | 가중치 | 이유 |
|:---:|:---:|------|
| 1 (STAND) | -5.0 | 서기 중에도 약한 억제 |
| 2 (WALK) | -15.0 | 떨기 전략 비용 급상승 |
| 3 (TROT) | -20.0 | 깔끔한 보행 강제 |

## 5. 예상 학습 경로

```
Phase 1 (iter 0~2000): 서기 학습
  - V18.1과 동일 속도 (standing_height=40 유지)
  - joint_oscillation 약한 억제(-5.0)로 과도한 진동은 사전 방지
  - ~iter 1000에서 안정 서기 달성

Phase 2 (iter 2000~6000): 보행 전환 ← 핵심 구간
  - standing_height 8.0으로 감소 → 서기만으론 보상이 부족
  - joint_oscillation -15.0으로 떨기 전략 비용 급상승
  - forward_velocity 12.0으로 이동 인센티브 대폭 강화
  - joint_vel_l2 -0.5로 떨기 추가 페널티
  → "떨기 대신 걷기"를 탐색할 가능성 증대
  → 걸으면 gait_cycle/stride가 자연스럽게 > 0 → 추가 보상 획득

Phase 3 (iter 6000+): 트로트 수렴
  - gait_cycle 15.0 + stride 12.0으로 패턴 정제
  - 과속 페널티 -20.0으로 깔끔한 보행 강제
```
