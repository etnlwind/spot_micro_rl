## 3. 진단: "벌레 걸음(Bug Walking)" 데드락

### 3.1 관찰된 행동

로봇이 **서서 다리만 초고속으로 떨고 있음**:
- 체고 유지 (standing_height 극대화)
- 다리 관절 속도 ~20 rad/s (미세진동)
- 실제 보행(전진 이동) 없음
- 발이 지면에서 제대로 떨어졌다 착지하는 "걸음" 패턴 부재

### 3.2 왜 gait_cycle_period = 0인가

`gait_cycle_period_reward` 함수의 3중 필터 구조:

```
① 이벤트: 같은 발의 touchdown 2회 이상 필요
② 측정값: period > 0 (같은 발 2번째 접지여야 측정됨)
③ 전진 게이팅: vel_x / 0.05 (clamp 0~1)
```

**문제 원인**:
- 로봇의 "초고속 미세진동"은 정상적인 접촉→비접촉 전환이 아님
- 만약 touchdown이 감지되더라도 period ≈ 0.02s → target 0.3~0.5s 범위에서 극히 먼 거리
- `exp(-distance²)` ≈ `exp(-100)` ≈ 0
- **③ 전진 게이팅은 문제가 아님** — vel_x ≈ 1.0~1.7로 통과하고 있었음

### 3.3 왜 stride_length = 0인가

`stride_length_reward` 함수의 3중 필터 구조:

```
① 이벤트: liftoff → touchdown 쌍 필요
② 측정값: stride > 0.001 (발 XY 이동 1mm 이상)
③ 전진 게이팅: vel_x / 0.05 (clamp 0~1)
```

**문제 원인**:
- 발이 거의 이동 없이 제자리에서 빠르게 올렸다 내림
- XY 이동 거리 ≈ 0 → `stride > 0.001` 필터 통과 불가

### 3.4 근본 원인 — 보상 구조적 데드락

```
서기 보상(standing_height=40→20) 극대화가 최우선
         ↓
"서서 다리만 빠르게 떨기"가 최적 전략
         ↓
유효한 접촉 전환 이벤트 미발생
         ↓
gait_cycle/stride 함수 출력 = 0
         ↓
가중치 × 0 = 0 → Phase 2에서도 무의미
         ↓
PPO의 엔트로피만으로는 탈출 불가 (선행 탐색 문제)
```

## 4. 결론

- **iter 15,000까지 돌려도 걷기 학습 불가능**
- Phase 2의 gait_cycle/stride 가중치가 올라가도 `가중치 × 0 = 0`
- "서서 떨기" 전략이 현 보상 구조에서 지역 최적
- **V18.2에서 보상 구조 수정 + from scratch 재훈련 필요**
- 이유: Lesson #4 — "Critic reset + fine-tune fails with large reward changes → train from scratch"
