## 실패 원인 분석

### 1. band_high가 역효과

V29에서 `band_high=0.65`를 추가해 FL/FR 0.83+ 고착을 해제하려 했으나:

```
contact_residency band = [0.25, 0.65]
FL/FR contact = 0.84 → band 밖 (초과) → residency reward = 0
```

**FL/FR이 이미 band_high를 초과**하여 reward도 gradient도 없음.
residency reward가 FL/FR에게 완전히 비활성화 상태.

### 2. per_leg_contact_target_band도 비작동

```
target_band = [0.20, 0.45]
RL/RR contact = 0.48~0.53 → band 밖 (초과) → reward = 0
FL/FR contact = 0.84 → band 밖 → reward = 0
```

**전체 4발 모두 band 밖** — weight=0.5이지만 실제 gradient 없음.

### 3. front_rear_support_balance_penalty 비활성

```
weight = 0.0 (disabled)
실제 gap = 0.36 > max_diff 0.50
```

앞다리 지배 구조에 대한 명시적 패널티가 없어 구조적 편중 방치.

### 4. enforce 타이밍이 너무 이름

```
residency_relay_up_start = 600
iter 625부터 enforced_fail → reward -100 수준 패널티
```

gait B 달성 직후 바로 enforce 진입. 기본 걸음새 안정화 전에 강한 패널티 → gait 퇴행 (B → C).
